# Featured Projects

## 1. PhysioVision

AI-powered physiotherapy management and exercise analysis platform designed to assist physiotherapists in monitoring patient performance and tracking exercise accuracy.

### Key Features

- Real-time pose estimation and landmark tracking.
- Frontend-based biomechanical calculations and joint-angle analysis.
- Exercise-specific finite state machines for movement tracking.
- Phase-wise locking and cycle-based repetition validation.
- Live exercise accuracy scoring and audio feedback.
- Custom exercise creation and assignment by physiotherapists.
- Patient progress tracking, session summaries, and historical analysis.
- Separate physiotherapist and patient dashboards.

### Architecture & Tech Stack

`React.js` `JavaScript` `MediaPipe` `Node.js` `Express.js` `MongoDB` `Mongoose`

## 2. Sahayak

A geo-aware hyperlocal job marketplace connecting customers with nearby service providers through structured worker-client workflows.

### Key Features

- OTP-based authentication with Redis-backed verification.
- JWT access and refresh token authentication.
- Role-based access control and session management.
- Worker and customer profile management.
- Worker skills and service-address management.
- PostgreSQL-backed relational data architecture.
- Modular backend with repository-based database access.
- Structured foundation for job management and worker discovery.

### Architecture & Tech Stack

`React.js` `JavaScript` `Node.js` `Express.js` `PostgreSQL` `Redis` `Zod` `JWT` `Socket.io` `Twilio`
